# Food & Beverage E-Commerce Website 🍔

## About the Project
A responsive Food & Beverage E-Commerce Website developed using HTML5 and CSS3 to provide an attractive and user-friendly interface for browsing food and beverage products.

## Features
- Browse food and beverage products.
- Responsive layout for different screen sizes.
- Attractive product presentation.
- Organized website sections.
- Simple and user-friendly navigation.

## Technologies Used
- HTML5
- CSS3

## How to Run
1. Download the project files.
2. Extract the files.
3. Open `index.html` in your browser.
